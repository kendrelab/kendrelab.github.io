Downloadable files live here. Two groups of folders.

RESOURCES PAGE  — "Reagents, protocols and data"
  files/plasmids/    plasmid maps, sequences, construct archives
  files/protocols/   bench protocols and SOPs
  files/datasets/    data tables, supplementary files
  files/code/        scripts and pipelines

  To add:    1. copy the file into the right folder
             2. open data.py, find RESOURCES, add one line:
                  ("protocols", "CCA organoid culture", "files/protocols/cca-organoids.pdf"),
             3. rebuild
  To remove: delete that line (and the file). The card goes back to
             "ask us" on its own — nothing is left dangling.

TEACHING PAGE — course material
  files/ls3003/  files/ls3075/  files/ls1001/  files/ls3606/  files/ls6011/

  Same idea: add the file, then add it to that course's "materials" list
  in COURSES in data.py.

Filenames: lowercase, hyphens, no spaces. GitHub Pages serves everything in
this folder publicly — do not put anything here you would not publish.
